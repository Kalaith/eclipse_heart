# Eclipse Heart Docs

- `RULES.md` is the formal rules reference and the source of truth for match behavior.
- `IMPLEMENTED_SYSTEMS.md` tracks shipped systems and current behavior.
- `CARD_TEMPLATE_SPEC.md` defines the card frame, badge, and art layout used by `assets/generated/cards/`.
- `verification/` holds reference UI captures.

Engineering guidance lives in the repo-root `AGENTS.md`, `CODE_STANDARDS.md`,
`GAME_DEVELOPMENT_GUIDE.md`, and `MACROQUAD_TOOLKIT.md` (synced from
`rust_management/docs/`). Outstanding work lives in the repo-root `TODO.md`.
